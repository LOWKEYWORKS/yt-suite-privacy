# YT Suite Privacy Policy

Last updated: August 16, 2026

YT Suite is a browser extension designed to enhance the YouTube viewing experience with features including Music Handoff, video brightness controls, and Moment Peek timestamp previews.

## Data Collection

YT Suite does not collect, sell, transmit, or share personal information with external servers.

The extension does not collect:
- Personal identification information
- Authentication information
- Financial or payment information
- Health information
- Personal communications
- Precise location information
- Browsing history for advertising or profiling purposes

## Local Storage

YT Suite uses Chrome's local storage functionality to save extension preferences, such as:
- Brightness settings
- Moment Peek preferences
- Music Handoff preferences
- Other YT Suite configuration settings

These preferences remain stored locally in the user's browser and are not transmitted to YT Suite servers.

## YouTube Page Access

YT Suite requires access to YouTube pages in order to provide its user-facing features.

This access is used only to:
- Integrate YT Suite tools into the YouTube player interface
- Identify the currently active YouTube video when required for a feature
- Provide Music Handoff functionality
- Provide video brightness controls
- Generate Moment Peek previews for timestamps shown on the currently viewed YouTube page

YT Suite does not use this access for advertising, profiling, tracking, or selling user data.

## Remote Code

YT Suite does not execute remotely hosted JavaScript or WebAssembly code.

All executable extension code is included within the extension package distributed through the Chrome Web Store.

## Data Sharing

YT Suite does not sell or share user data with third parties.

YT Suite does not use user data for advertising, creditworthiness, lending, or unrelated purposes.

## Limited Use

Any access to user data is limited solely to providing and improving the user-facing functionality of YT Suite.

## Changes to This Policy

This Privacy Policy may be updated if YT Suite's features or data practices change.

Any updated version will be published at this same URL.

## Contact

For privacy-related questions regarding YT Suite, users may contact the developer through the support options provided on the Chrome Web Store listing.
